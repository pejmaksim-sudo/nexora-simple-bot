NEXORA — простой бот для приема заявок.

Бот делает только самое необходимое:
1. Клиент нажимает «Оставить заявку».
2. Указывает услугу.
3. Описывает задачу.
4. Указывает место.
5. Указывает дату/время.
6. Оставляет телефон.
7. Готовая заявка приходит администратору в Telegram.

Также есть:
- «Как работает NEXORA»
- «Связаться с менеджером»

Запуск:
pip install -r requirements.txt
BOT_TOKEN="..." ADMIN_CHAT_ID="..." python bot.py

Не публикуйте BOT_TOKEN: Telegram рекомендует хранить его как пароль.
